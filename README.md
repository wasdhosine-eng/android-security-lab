# Android Security Lab — مختبر تحليل تطبيقات أندرويد

موقع تعليمي تفاعلي يعمل بالكامل داخل المتصفح، بلا خادم ولا تسجيل حساب.

## محتويات المشروع

- `index.html` الصفحة الرئيسية وهيكل الواجهة.
- `style.css` التصميم والألوان ومتجاوب مع الهواتف.
- `data.js` التطبيقات التجريبية والقواعد والدروس والاختبارات.
- `app.js` منطق المختبر: التفكيك المحاكى والشجرة والمحرر والتحليل.
- `README.md` هذا الملف.

## ما الذي يفعله المختبر؟

- **APKTool:** محاكاة لتفكيك تطبيق تجريبي مع شريط تقدم وشجرة ملفات وبحث داخل الأكواد.
- **Smali:** عرض الصنوف والدوال والحقول والعلاقات مع أرقام الأسطر وتلوين الصياغة.
- **تحليل الأمان:** تلوين الملفات بالأخضر والأصفر والبرتقالي والأحمر حسب الأسطر الفعلية، وشرح سبب كل لون.
- **التجسس:** اجتماع الصلاحيات الحساسة مع الشبكة والتشغيل الخلفي، وطرق الحماية.
- **Telegram:** محاكاة وهمية بالكامل توضح الفرق بين اتصال مشروع وآخر مشبوه.
- **المحرر:** تعديل الملفات التجريبية، ومقارنة قبل وبعد، والتراجع، وفحص الأخطاء البسيط.
- **الصلاحيات والدروس والاختبارات:** محتوى عربي متدرج مع نقاط ومستويات محفوظة في المتصفح.

ملاحظة صادقة: المختبر لا يفكّك ملفات APK حقيقية. الملفات معروضة نماذج مكتوبة لأغراض الشرح، وكل التلوين الأمني ناتج عن قواعد تُطبَّق على أسطر هذه النماذج.

## النشر على GitHub Pages من الهاتف

1. أنشئ حساباً على GitHub إن لم يكن لديك، ثم أنشئ مستودعاً جديداً باسم مثل `android-security-lab` واجعله Public.
2. افتح صفحة المستودع من متصفح الهاتف، واختر **Add file** ثم **Upload files**.
3. ارفع الملفات الخمسة. هي في مجلد واحد بلا مجلدات فرعية، لذلك يسهل رفعها من الهاتف.
4. اضغط **Commit changes**.
5. ادخل إلى **Settings** ثم **Pages**، واختر في Source: `Deploy from a branch`، والفرع `main` والمجلد `/ (root)`، ثم **Save**.
6. بعد دقيقة أو دقيقتين سيظهر رابط الموقع بالشكل: `https://اسم-المستخدم.github.io/android-security-lab/`

إذا لم تظهر خيارات الإعدادات في متصفح الهاتف، فعّل خيار "Desktop site" من قائمة المتصفح.

## التشغيل المحلي

يكفي فتح ملف `index.html` في المتصفح. لا يحتاج المشروع إلى تثبيت أو مكتبات.

## ملاحظات

- التقدم والنقاط يُحفظان في `localStorage` داخل متصفحك فقط.
- الخطوط تُحمَّل من Google Fonts، وإن تعذّر تحميلها يعمل الموقع بخط احتياطي.
- المحتوى تعليمي، ولا يجوز استخدام أدوات التفكيك على تطبيقات لا تملك حق تحليلها.
